Players manage a virtual portfolio of real S&P 500 names and compete on a perpetual leaderboard. Quotes and historical OHLCV bars are ingested from external REST providers into TimescaleDB, which is the single source of truth for every fill, valuation, and ranking. TypeScript end to end, with contracts shared across the wire.

Containers & components

  • − Docker — Compose stack on one VPS
    • PostgreSQL — system of record
    • TimescaleDB — price_bar hypertable
    • Redis — queue · cache · rate limits
    • − Fastify — one image, three roles (ROLE env)
      • React — Vite + TypeScript SPA
      • 🌐 API — auth · orders · reads · WS
      • 🤖 Bot runner — seeds the index bot
      • ⚙️ Worker — ingest · daily price · snapshot
